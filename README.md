# The Quiet Rewrite: LLM-Assisted Writing in Online Petitions (2011–2024)Final course project — data analysis. What this project showsAcross **1.33 million petitions** from **11 sources** (five UK Parliament archives, Scotland, Canada, Russia, Korea's Blue House, and the 964k-petition English Change.org release of Corpus et al. 2026), large-language-model writing style became a routine part of citizen petitioning after ChatGPT's release — and it doesn't help:* **Prevalence (lower bounds, dictionary-free split-half excess-vocabulary estimator):** ≥17.9% \[14.5, 21.6] of UK parliamentary petitions by 2024Q1 (a conservative mean-anchored variant converges at 18.6%); 7.9% \[7.6, 8.1] on Change.org by end-2024. **Australia is a natural experiment**: with no in-platform AI tool, its organic floor is 4.9% \[3.0, 6.6] in 2023Q4 and jumps to 11.6% \[10.4, 13.1] — CIs fully separated — the exact quarter the tool arrives.* **Causal timing:** UK event study flat for 11 pre-quarters (max 0.078 SD), then a ramp to +0.33 SD; 0/400 permutation placebo dates match it.* **The same people changed:** within-writer fixed effects on Change.org user IDs: **+0.62 SD** (7,250 repeat authors; 25.4% jumped >1 SD).* **Model-free confirmation:** a distilgpt2 trained only on pre-2022 petitions finds post-2022 text increasingly *predictable* (NLL ratio 0.86–0.95) while pre-cutover falsification quarters sit at 1.00.* **Consequences:** −7.0% signatures per +1 SD of LLM style in growth-immune specifications (−12.6% on UK 2019), 15–19% lower odds of reaching the 10k/100k thresholds, and a reversed moderation association — versus a null/positive pre-2022 benchmark.Every claim traces to a file in `outputs/`; all 27 identified threats to validity have computed statuses in `outputs/BIAS\\\_AUDIT\\\_v6.md`; confirmatory hypotheses were pre-specified in `outputs/PREREG\\\_v6.md`, generated verbatim from the frozen analysis code before any confirmatory result existed.## Repository map```notebooks/  petition\\\_llm\\\_pipeline\\\_FINAL.ipynb  <- THE pipeline, one file: collection -> cleaning ->                                        features -> analyses 11.1-11.20 -> findings summary.                                        noutputs/    all aggregate result tables (TAB\\\_\\\*.csv), figures (FIG\\\_\\\*.png), the bias-audit            dashboard, and the frozen analysis plan — no raw petition text anywherepaper/      the 5-page two-column paper (main.tex, figures, compiled PDF)```## Reproducing the analysis**Environment:** Google Colab, A100 GPU + High-RAM runtime recommended (standard GPU works;
